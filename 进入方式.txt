==============================================
  康伴 · AI 个人健康问答助手 —— 进入方式
==============================================

本软件提供两种进入方式，任选其一即可：

  【方式一】双击「启动助手.bat」自动启动（最简单，推荐）
  【方式二】手动输入 CMD 命令启动（见下方详细步骤）


----------------------------------------------
 方式二：用 CMD 命令行安装并进入网页
----------------------------------------------

第 1 步：确认已安装 Python
  按下键盘 Win + R 键，输入 cmd 后回车，打开命令窗口。
  在窗口中输入以下命令并回车：

      python --version

  · 如果显示类似 "Python 3.10.x" 或更高版本，说明已安装，继续第 2 步。
  · 如果提示 "不是内部或外部命令"，说明没有安装 Python，
    请先到官网下载安装：https://www.python.org/downloads/
    （安装时务必勾选 "Add Python to PATH"）


第 2 步：进入本文件夹
  在命令窗口中输入（注意路径中如有空格，请用引号包住）：

      cd /d "本文件夹的完整路径"

  例如解压到 D 盘根目录，则输入：

      cd /d "D:\health-ai-assistant"

  （提示：可以在文件夹地址栏复制完整路径，粘贴到命令里更省事）


第 3 步：安装依赖（首次运行只需一次，约 1 分钟）

      pip install -r requirements.txt


第 4 步：启动应用

      streamlit run streamlit_app.py


第 5 步：打开网页
  运行成功后，命令窗口会显示一个网址（通常是 http://localhost:8501）。
  浏览器一般会自动打开；若没有，请手动在浏览器地址栏输入：

      http://localhost:8501

  即可进入「康伴」健康问答助手页面。


----------------------------------------------
 关于 AI 智能回答（可选）
----------------------------------------------
  未配置密钥时，应用会自动进入「演示模式」，界面与交互均可正常使用。
  如需体验真实 AI 回答，请：

  1. 到 https://platform.deepseek.com/ 注册并获取 API Key；
  2. 将本文件夹 .streamlit 目录下的 secrets.toml.example
     复制一份，改名为 secrets.toml；
  3. 用记事本打开 secrets.toml，把其中的
     sk-xxxxxxxxxxxxxxxx 替换成你自己的 Key 并保存；
  4. 重新运行应用即可。


----------------------------------------------
 常见问题
----------------------------------------------
  Q: 提示 "pip 不是内部或外部命令"？
  A: 说明 Python 安装时没有勾选 "Add Python to PATH"，
     请重新运行 Python 安装程序，勾选该选项后再试。

  Q: 提示 "No module named streamlit"？
  A: 说明依赖没装好，重新执行第 3 步：
     pip install -r requirements.txt

  Q: 端口被占用？
  A: 可换一个端口启动：
     streamlit run streamlit_app.py --server.port 8502
     然后访问 http://localhost:8502
